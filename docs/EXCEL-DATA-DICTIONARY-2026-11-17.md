# قاموس بيانات قالب CHM-SFD التشغيلي

تاريخ الاستخراج: 17 نوفمبر 2026

## نتيجة التحقق

- عدد أوراق المصنف الفعلي: **33** ورقة.
- ورقة «اقرأني» تذكر 22 ورقة؛ هذا الوصف غير محدث. اعتمدنا أسماء الأوراق وعناوين الصف الأول الموجودة فعلياً في الملف.
- تم استخراج أسماء الأعمدة فقط لهذا القاموس؛ لم تُنقل سجلات البيانات أو الأسرار إلى هذا التقرير.
- لم تُنفذ أي Migration أو عملية استيراد إلى قاعدة بيانات.

## الفجوة الأولية مع Prisma

مخطط Prisma الحالي يحتوي على النماذج: `User`, `ComplaintOperation`, `FieldAwareness`, `FieldBox`, `BoxOpeningMinute`, `InventoryItem`, `AuditLog`. لا يمثل المخطط الحالي كل أوراق القالب؛ وتحتاج بقية الأوراق إلى نماذج وعلاقات مستقلة أو توثيق مبرر لدمجها. لا يجوز اختزال الإحالات أو المرفقات أو سجلات الحضور أو حركات المخزون في حقل نصي واحد.

## قرارات تصميم لازمة قبل Prisma migrations

1. رقم المشروع مفتاح مرجعي، مع حفظ بيانات المشروع التاريخية اللازمة للتقارير دون فقد العلاقة بالمصدر المرجعي.
2. الموقع علاقة متدرجة: المحافظة ← المديرية ← العزلة ← القرية/الحي.
3. التصنيف علاقة متدرجة من ثلاثة مستويات.
4. الإحالة، المتابعة، الردود، المرفقات، الحضور، وحركات المخزون سجلات متعددة مرتبطة بمعرف العملية أو النشاط؛ لا تستبدل السجلات السابقة.
5. فصل مستخدمي النظام التشغيليين وصلاحيات الفروع عن جداول جلسات Better Auth، أو توثيق الربط بينهما صراحةً. المخطط الحالي يحتوي Prisma `User` بينما Drizzle يعرّف جدول `user` منفصلاً.
6. مراجعة اختلاف أسماء الأعمدة المتكررة/المتباينة (مثل «ملاحظات» و«تاريخ الإدخال») دون تغيير المصنف الأصلي.
7. بناء خريطة مواءمة نهائية لكل عمود: نوع البيانات، الإلزامية، المفتاح، العلاقة، قواعد التحقق، مصدر المزامنة، وسياسة الاحتفاظ.

**الحالة:** قاموس عناوين أولي موثق؛ ليس اعتماداً نهائياً لمخطط قاعدة البيانات.
